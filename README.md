# Doppelkopf Online

Öffentliche Laufzeitdateien der Doppelkopf-App für Online-Spielabende.
Streamlit-Einstieg: `streamlit_app.py`, Python 3.12.
Datenbankverbindungen werden ausschließlich als Hosting-Secrets gesetzt.
Dieses Repository enthält keine Spielerdaten, Backups oder Excel-Dateien.
Automatisch veröffentlicht; Änderungen werden im privaten Quellrepository geprüft.
